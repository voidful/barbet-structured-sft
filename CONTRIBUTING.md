# Contributing

Open an issue for a reproducible bug or a concrete improvement. For model
behavior reports include the model revision, full non-sensitive request,
decoding settings, package versions and the unmodified output. Do not post
private datasets, access tokens or personal information.

Keep changes focused. Run `python scripts/validate_release.py`, preview
`site/`, and explain the observed before/after behavior in your pull request.
Do not update recorded model outputs by hand. New evaluation claims need
frozen inputs, source/model identities and raw results. Keep held-out
evaluation examples out of training.

Documentation corrections and issue reports are welcome. Because an
explicit project license is still pending, contributors should confirm
the applicable terms before submitting reusable code or data. No implied
broad license grant is created by this contribution guide.
