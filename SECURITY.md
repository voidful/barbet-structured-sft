# Security

## Supported release

Reports about the current `0.1.x` public inference scripts, runtime and
publication workflow are welcome. No fixed response-time guarantee is made.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/voidful/barbet-structured-sft/security/advisories/new)
for exploitable code or credential exposure. Include affected revisions
and a minimal, non-sensitive reproduction. Do not open a public issue
containing credentials or an unpatched exploit.

Incorrect model answers, hallucinations and the documented instruction
failures are capability reports; use the behavior-report issue template.
Inspect custom model code and pin revisions before deployment. This model
has not been validated for autonomous or high-stakes decisions.
