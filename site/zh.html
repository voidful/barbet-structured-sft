01 / 模型概覽

輸入文字，產生結構化判定。

處理 ASR 逐字稿候選、TTS 書寫與口語形式、OCR 文字候選、翻譯修訂。請求包含明確任務契約與可見參照證據；模型沒有內建音訊、影像編碼器或語音波形產生器。

04 / 開始使用
執行一個完整的結構化請求。
載入器保留原始 BF16／FP32 精度配置。範例中的 assistant 參考答案不會送入模型提示。
TERMINAL
git clone https://github.com/voidful/barbet-structured-sft.git
cd barbet-structured-sft
python -m venv .venv
source .venv/bin/activate
python -m pip install torch==2.11.0 packaging ninja setuptools wheel
python -m pip install --no-build-isolation -r requirements-inference.txt
python scripts/infer.py --example ocr_correction --device cuda:0
已測環境：Python 3.12 · PyTorch 2.11 · CUDA 13.0 · H200。原生 Mamba 套件需相容 CUDA 建置環境；短輸入亦支援 CPU。
