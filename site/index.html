01 / Overview

Text in. Structured decisions out.

Work with ASR transcripts, TTS written and spoken forms, OCR candidates, and translation revisions. Requests include explicit task contracts and visible reference evidence. Audio encoders, image encoders and speech waveform generation are not included.

ASRTTS textOCRTranslation
Know the boundary

Free-form instructions: 0/16 on the fresh diagnostic set. Code BPB regresses 27.36%; mathematics 16.21%. This is a specialized experimental checkpoint, with no demonstrated SFT 1M capability.

Long input is still an open limitation
In a small controlled raw-continuation probe, SFT finds the four 8K codes but adds a full stop. At 128K, only the near-end code appears, with extra continuation. Strict exact remains 0/4 at both lengths. A configured 1M context limit is not a demonstrated capability.

04 / Quick start
Run a complete structured request.
The loader preserves the original BF16 / FP32 parameter mix. The example’s assistant reference is never included in the prompt.
TERMINAL
git clone https://github.com/voidful/barbet-structured-sft.git
cd barbet-structured-sft
python -m venv .venv
source .venv/bin/activate
python -m pip install torch==2.11.0 packaging ninja setuptools wheel
python -m pip install --no-build-isolation -r requirements-inference.txt
python scripts/infer.py --example ocr_correction --device cuda:0
Tested: Python 3.12 · PyTorch 2.11 · CUDA 13.0 · H200. Native Mamba packages require a compatible CUDA build environment. Short CPU inference is supported.


05 / Documentation
Source, evidence, and reproducibility.
Training covered every one of the 980,000 examples once, without truncation. Public inference and synthetic-data evaluation are documented. Exact retraining additionally needs the separately controlled base checkpoint; the historical retention corpus is not distributed.
