# Original training and evaluation source

These files preserve the executed SFT implementation. The trainer and
`sft_common.py` are byte-identical to the files recorded in
`reports/training_summary.json`. This is a run archive with relative
`outputs/sft_20260916` defaults, not a generic training framework.

See [reproduction instructions](../docs/reproducing.md) before running.
Exact retraining needs access to the separately hosted pre-SFT base.
The historical retention corpus is not included. No training is run by CI.
